**USER JOURNEY**

**Student Lost-and-Found Mobile App**
 
Role: Task Flows & User Journeys

# 1\. User Journey: Student Who Lost an Item

Goal: To help a student report a lost item, search for a possible match, submit a claim, and recover the item.

| **Stage**            | **User Action**                                          | **User Need/Goal**                      | **System Response**                    |
| -------------------- | -------------------------------------------------------- | --------------------------------------- | -------------------------------------- |
| 1\. Item Lost        | Student realizes an item is missing                      | Find the lost item                      | Student opens the app                  |
| 2\. Open App         | Student opens the Lost-and-Found app                     | Access lost-and-found services          | Home screen is displayed               |
| 3\. Report Lost Item | Student selects Report Lost Item                         | Report the missing item                 | Lost-item form is displayed            |
| 4\. Enter Details    | Student enters item name, description, location and date | Provide information about the lost item | System accepts the details             |
| 5\. Add Image        | Student adds an image of the item                        | Help identify the item                  | Image is attached to the report        |
| 6\. Submit Report    | Student submits the report                               | Register the lost item                  | System confirms submission             |
| 7\. Search Items     | Student searches found items                             | Find a possible match                   | Search results are displayed           |
| 8\. View Item        | Student selects a possible matching item                 | Verify whether it is theirs             | Item details are displayed             |
| 9\. Submit Claim     | Student submits a claim                                  | Request recovery of the item            | System records the claim               |
| 10\. Track Claim     | Student checks claim status                              | Know whether the claim was accepted     | System displays claim status           |
| 11\. Recover Item    | Student receives confirmation                            | Collect the item                        | System provides collection information |

# 2\. User Journey Flow

Item is Lost  
↓  
Open App  
↓  
Report Lost Item  
↓  
Enter Item Details  
↓  
Add Image  
↓  
Submit Report  
↓  
Search Found Items  
↓  
View Possible Match  
↓  
Submit Claim  
↓  
Track Claim  
↓  
Recover Item

# 3\. User Goal

The user journey is designed to make it easy for a student to report a missing item, search for a possible match, submit a claim, and track the claim until the item is recovered.
