# Problem Statement: Student Lost-and-Found Mobile App

## 1. The Core Problem
Every semester, hundreds of valuable items are lost on the **Dedan Kimathi University of Technology** campus. This includes student ID cards (blocking lab access), smartphones, laptops containing critical assignment data, keys, and wallets. 
Currently, there is **no centralized system** to report or search for these items. The university relies on:
- Physical lost-and-found boxes located at different security booths (students don't know which booth to go to).
- Scattered WhatsApp and Facebook posts that get buried within hours.
- Word-of-mouth, which is highly unreliable.

## 2. Impact on Users
- **Wasted Time**: Students often visit 3-4 different campus offices before finding their item, taking up to 2 hours.
- **Financial Loss**: Replacing an ID card costs ~$20; replacing a laptop is hundreds of dollars.
- **Academic Stress**: Losing notes or a USB drive right before exams causes severe anxiety.

## 3. Project Scope (What we are building)
**Included in the Mobile App Prototype:**
- Report a lost item (with category, description, location, date/time, and photos).
- Report a found item (with description, location, date/time, and photos).
- Search and filter items by category, location, and date.
- Submit a claim for a found item.
- Track the status of your claims (Pending, Approved, Rejected).

**Not Included (Out of Scope):**
- Real-time GPS tracking of items.
- Integration with the university's student database (no API access).

## 4. Success Criteria
1. A first-time user can report a lost item in under **3 minutes**.
2. A user can find a potential match in search in under **2 minutes**.
3. **80%** of usability testers complete all tasks without assistance.
4. Users rate the app's ease of use at **4 out of 5 or higher**.
